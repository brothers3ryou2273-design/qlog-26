# チャレンジの調査・部分収録（第11段階）

2026-10-16確認。日本版MHXXを対象とし、実機確認なし。攻略レシピのトップページから「チャレンジ」http://wiki.mhxg.org/data/2034.html を辿り、掲載20件と全個別ページをHTTP取得した。ハンター14件・ニャンター6件を、通常闘技大会・イベントと別カテゴリで収録する。

これは日本版MHXXの全件数の確定ではない。専門Wiki https://w.atwiki.jp/mhxxnyanter/pages/70.html には「ＸＸイベント：火竜討伐」「轟竜討伐」「迅竜討伐」「雷狼竜討伐」「砕竜討伐」「大連続狩猟４」のニャンター6項目が追加掲載されている。攻略レシピにある同モンスターのハンター版や「大連続狩猟4」へ統合しない。正式名・個別ページ・日本版での収録範囲を独立確認する資料が不足しているため、今回のランタイムには追加せず、観測・保留対象として監査する。他にも未照合の追加クエストがある可能性があり、未収録数を6件に確定しない。

既存ニャンター6件のサポート傾向とS/A/B表記は同専門Wikiで照合。ハンター14件の武器種・評価時間、全20件の難易度区分・数値HRは今回取得資料で未確認であり、推測値を登録しない。共通ダウンロード要件はカテゴリ説明に置き、全件の条件をunknownにはしない。現在の配信可否も未確認。

コイン・チケットの個別用途を確認した装備の生産・強化経路のみを個別の解放情報へ登録する。横断達成報酬や「全A／全S」は単独報酬へ複製せず、クリアチェックだけで自動判定しない。

指定の補助DBは最初HTTPS CONNECT 403、許可後HTTPSは25秒タイムアウト。HTTPではページを取得できたが、/quest/?no=7 と no=8 の一覧はクエスト行が空で、0件の実在一覧とは判定しない。HTTPの解説ページは取得済みだが、虚心のピアスを初回クリアとする記述は攻略レシピと異なるため採用しない。カプコン公式マニュアルはHTTP 403で本文を確認できず、公式確認済みとは扱わない。
