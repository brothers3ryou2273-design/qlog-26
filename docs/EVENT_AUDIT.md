## 表示・条件

イベントは下位・上位・G級で選択。旧 `event / 全ランク` は下位へ移行し、検索・種別・未クリア・プレイ種別を保持する。通常クエスト・特殊許可との進捗は独立する。

数値HRは個別の備考に記載された値だけ採用。下位の数値HRは原資料に記載がなく、推定のHR1を登録しない。「記録で判定する前提なし」は配信不要の意味ではない。防具・護石未装備、弾・ビンポーチ以外の持込禁止は独立した外部条件として残す。

## 素材と装備

クエストの特別な報酬素材から、その素材の実在ページにある生産・強化先と必要個数を調べる。素材を入手すること、加工屋で生産可能になること、装備を所持することは別。別途必要な他素材・費用・進行条件を省略せず共通注記し、クリアだけで製法フラグや装備取得を保証しない。通常素材や一般的な狩猟証だけでは解放表示にしない。
